🎯 Quick Deploy (2 Options)

Method 1: Deploy via Dashboard (Easiest - 5 minutes)

Open Cloudflare Dashboard

Open Cloudflare Dashboard →

Create Project

Click "Workers & Pages" → "Create application" → "Pages" → "Connect to Git"

Connect GitHub

Select repository: mrv0for0vandeta/patrimoine

Configure Build
  • Framework: None
  • Build command: (leave empty)
  • Build output: frontend
Add Environment Variables

In Settings → Environment variables, add these 7 variables:

DATABASE_URL
NODE_ENV
JWT_SECRET
SESSION_SECRET
ADMIN_USERNAME
ADMIN_PASSWORD
ADMIN_EMAIL
Deploy!

Click "Save and Deploy" - Your site will be live in 1-2 minutes! 🎉

Method 2: Deploy via Command Line (3 commands)

# Install Wrangler CLI
npm install -g wrangler

# Login to Cloudflare
wrangler login

# Deploy
npm run deploy:cloudflare

Then add environment variables via dashboard (see Method 1, Step 5)

✅ After Deployment

Your site will be live at:

https://moroccan-heritage-survey.pages.dev/
