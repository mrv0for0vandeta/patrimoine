==========================================
COMMAND TO PUSH TO GITHUB
==========================================

Once you have a token with WRITE permissions, run this:

cd C:\Users\HP\Desktop\gjfi
git push https://YOUR_NEW_TOKEN@github.com/edjhd146-gif/patrimoine.git main

Replace YOUR_NEW_TOKEN with your new token.

==========================================
HOW TO GET A TOKEN WITH WRITE ACCESS
==========================================

1. Go to: https://github.com/settings/tokens

2. Click "Generate new token" → "Classic"

3. Give it a name: "Patrimoine Project Push"

4. Select these scopes:
   ✅ repo (this gives full access to private repos)
      ✅ repo:status
      ✅ repo_deployment  
      ✅ public_repo
      ✅ repo:invite
      ✅ security_events

5. Set expiration: 90 days (or No expiration if you prefer)

6. Click "Generate token"

7. COPY THE TOKEN (starts with ghp_...)

8. Use it in the command above

==========================================
ALTERNATIVE: USE GITHUB DESKTOP
==========================================

If tokens are giving you trouble, use GitHub Desktop:

1. Download: https://desktop.github.com/
2. Install and sign in
3. File → Add Local Repository
4. Browse to: C:\Users\HP\Desktop\gjfi
5. Click "Publish repository"
6. Done! ✅

This is the EASIEST method and handles authentication automatically.
