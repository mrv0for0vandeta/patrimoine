## 🆘 Troubleshooting

### Server Won't Start
```bash
# Check if port is in use
netstat -ano | findstr :3000

# Use different port
# Edit .env: PORT=3001
```

### Database Errors
```bash
# Reinitialize database
rm -rf data/
npm run init-db
npm run seed
```

### Missing Dependencies
```bash
# Reinstall
rm -rf node_modules package-lock.json
npm install
```
